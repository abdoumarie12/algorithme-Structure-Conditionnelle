Algorithme ValeurAbsolueDifference

Variable n1, n2, difference : entier

Début

    Afficher "Entrez le premier nombre"
    Saisir n1

    Afficher "Entrez le deuxième nombre"
    Saisir n2

    difference ← n1 - n2

    Si difference > 0 Alors
        Afficher "La valeur absolue est : ", difference
    Sinon
        Si difference = 0 Alors
            Afficher "La valeur absolue est : 0"
        Sinon
            Afficher "La valeur absolue est : ", -difference
        FinSi
    FinSi

Fin
